# BoatsTesting Branch

### Overview

This branch, `boatsTesting`, contains the setup for the **boats scene** in the project. It is specifically focused on testing the interactive gameplay elements within Unity's Game Test Interface.

### Purpose

- **Interactive Testing**: This branch is dedicated to testing the interactions and behaviors of game elements (such as player and bot interactions) without the complexity of AR components.
- **Unity Game Test Interface**: Allows testing within Unity’s simulation environment to streamline interactive development.

### Key Details

- **No AR Components**: This branch does not contain any AR-specific elements. All testing is done without positioning objects on a real-world surface.
- **Scripts Excluded**: There are no scripts in this branch related to positioning objects on a surface or specific locations. The focus here is purely on gameplay interactions and mechanics.

### Notes

This branch provides a simplified setup for refining game interactions and behavior, without any AR-related logic, creating a clean environment for gameplay testing and adjustments.
